# UPP JBTB 4 BALI — Website

Website statis responsif bernuansa Bali + PLN, siap dipublikasikan gratis melalui GitHub Pages.

## Fitur
- Hero Bali menggunakan aset `hero-bali.png` yang sudah ada di repository.
- Navigasi responsive dan mobile menu.
- Profil, pengunjung, rekomendasi Hotel/Kuliner/Wisata, serta Kontak & Layanan.
- Tombol backsound **Rindik Bali** berbasis Web Audio API, sehingga tidak membutuhkan file audio eksternal atau library tambahan. Browser biasanya membutuhkan satu klik pengguna sebelum audio dapat berbunyi.
- PWA manifest, favicon, robots.txt, dan 404 page.

## GitHub Pages
Repository ini bersifat public dan branch `main` siap digunakan. Aktifkan Pages melalui **Settings → Pages → Deploy from a branch → main → /(root)** jika belum aktif.

## Catatan
Audio yang digunakan pada versi ini adalah instrumental sintetis bernuansa Rindik Bali, dibuat agar website tetap ringan dan bebas dari ketergantungan file musik pihak ketiga. Untuk publikasi resmi, ganti data kontak dan pastikan aset/logo digunakan sesuai kewenangan dan pedoman identitas korporat.
