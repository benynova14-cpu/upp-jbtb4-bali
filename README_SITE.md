# UPP JBTB 4 Bali — Dynamic Free Website

Static, responsive website designed for free hosting on GitHub Pages or Cloudflare Pages.

## Features
- Responsive desktop/mobile layout
- Bali hero section
- Dynamic navigation and active section highlighting
- Interactive information cards and modal dialogs
- Local visitor counter using browser storage
- Contact form interaction
- Rindik-inspired background music using Web Audio (no paid library)
- Instagram and telephone links
- No server or paid database required

## Free hosting
- GitHub Pages: deploy the `main` branch with the site root.
- Cloudflare Pages: connect the repository, framework preset `None`, build command empty/`exit 0`, output directory `/`.
